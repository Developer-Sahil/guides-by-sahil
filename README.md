## How to use these guides

1. **Pick the guide that matches your goal.** Each one stands alone.
2. **Read the Table of Contents first.** Every guide has one, so you can jump to what you need.
3. **Follow the guide in order,** especially the learning paths — each phase builds on the last.
4. **Do the work.** The guides are only useful if you build the projects and hit the exit criteria.

New to everything? Start with the [VS Code Setup Guide](./vscode-setup-guide.md), then pick a learning path.

---

## How the guides are written

Every guide in this repo follows the same structure, so once you've used one, you know how to use them all:

- A table of contents with working links
- Numbered sections, kept short and direct
- Tables for comparisons and settings, code blocks for commands
- Callouts for tips and honest caveats
- A closing checklist so you can track your progress

Learning paths add a few more rules: every phase has **practice resources**, a **project to build**, and **exit criteria** — a concrete way to know you've actually learned the material, not just read it.
